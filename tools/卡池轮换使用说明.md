# 卡池轮换管理

双击同目录的 **启动卡池管理器.cmd**。程序使用本机Python标准库，不需要安装额外包。

1. 在上方搜索卡池名称、ID或卡组名。同一ID可能有多个历史档期，选择你需要的卡组。
2. 输入开始、结束时间，格式为 `2026-10-24 12:00`，全部按北京时间。
3. 点击“加入排期”。可添加多池同时开放，也可连续安排多轮。
4. 勾选“接管全部角色 / 武器卡池轮换”，再点“保存生效”。接管后，没有排期的池关闭；同类型同ID不允许时间重叠，首尾相接可以。
5. 运行中的新版服务端约1秒内读取设置并同步客户端。退出补给页，再进入以刷新列表；离线客户端下次登录会同步。

新增或移除后都需要保存。关闭管理窗口不会停止轮换，服务端会继续执行已保存排期。服务端重启后也会读取排期。

“恢复原版日期”关闭接管并保存，保留排期内容以供下次使用。每次覆盖保存前，旧设置自动备份到 `data/gacha-rotation-backups/`。恢复备份时将所需JSON复制为 `extracted/setting/gacha-rotation.json`，再重新打开管理器。

设置文件独立于原版gacha.txt，不修改原始日期、概率、价格或玩家存档。同类型同ID的历史档期仍共用原有保底与自选进度，轮换不会清零。原版的门票、通关条件仍有效，安排开放不等于自动解锁玩家条件。

当前已实现日期与卡组选择同步，不会自动点击界面、重启游戏或执行抽取。尚未完成的UP保底、免费抽取等规则不会因为排期开放而自动补齐；现有美术资源缺失也不会由本程序修复。

仅检查配置，不打开窗口：`python tools/gacha_manager.py --check`。

仓库内可运行 `python tools/gacha_manager.py --setting-dir /path/to/setting --lang-file /path/to/lang-zh-CN.json`。中文语言文件可省略，缺失时使用配置备注显示名称；配置表和语言文件仍由使用者自行准备，不随源码分发。未指定路径时从程序所在位置向上查找 `extracted/setting/gacha.txt`。
